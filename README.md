## Как запустить проект

### Требования
- PHP >= 8.1
- Composer
- Node.js & npm
- Git

### Установка

1. **Клонировать репозиторий**
```bash
git clone https://github.com/Fionina-Elena/devprofile.git
cd devprofile
```

2. **Установка зависимостей PHP**
```bash
composer install
```

3. **Настройка окружения**
```bash
cp .env.example .env
php artisan key:generate
```

4. **Установка зависимостей фронтенда**
```bash
npm install
```

5. **Сборка фронтенда**
```bash
npm run build
```

6. **Запуск сервера Laravel**
```bash
php artisan serve
```

7. **Открыть в браузере**
```
http://localhost:8000
```

 ## Почему Telegram вместо Email?

Вместо стандартной отправки писем на Email (SMTP) в проекте используется отправка уведомлений в Telegram-бота.

**Причина:** Проект хостится на платформе Render (бесплатный тариф), которая блокирует исходящие SMTP-соединения (порты 25, 465, 587), делая невозможной отправку писем напрямую через почтовые сервисы без перехода на платный тариф.

**Рассмотренные альтернативы:**
- **Яндекс.Почта (SMTP):** Connection timed out из-за блокировки портов хостингом
- **Unisender:** Проблемы с API версиями и правами доступа (Access Denied)
- **Brevo (Sendinblue):** Географические ограничения (недоступен в России)

**Итоговое решение:** Telegram Bot API выбран как наиболее надежное решение — использует HTTPS (порт 443), работает в России и не требует сложной настройки DNS или подтверждения доменов.

## Как реализована форма обратной связи

### Frontend (Vue.js)
- **Модальное окно** (ContactModal.vue)
- **Поля формы**:
  - Имя (обязательно)
  - Телефон (необязательно, с маской `+7 (###) ###-##-##`)
  - Email (обязательно)
  - Комментарий (обязательно)
- **Валидация на фронтенде** (HTML required атрибуты)
- **Отправка через Axios** на `POST /api/contact`
- **Состояния**: success, error, loading

### Backend (Laravel)
- **API endpoint**: `POST /api/contact`
- **Валидация на бэкенде** (ContactFormRequest.php)
- **Контроллер** (ContactFormController.php):
  - Валидирует данные
  - Отправляет уведомление в Telegram-бота
  - Возвращает JSON response

### Telegram уведомления
- **Отправка через Bot API**
- **Настройки:** config/telegram.php с использованием переменных окружения
- **Сообщение содержит:**
  - Имя отправителя
  - Телефон (если указан)
  - Email
  - Текст сообщения

### Обработка ошибок
- **Frontend**: отображение ошибок валидации под полями
- **Backend**: возврат ошибок валидации в JSON формате
- **Global error**: общее сообщение об ошибке отправки

```

  "name": "Елена Фионина",

  "email": "filatowa.l2010@yandex.ru",
  "message": "Тестовое сообщение"
}
```

### Response (успешный)
```json
{
  "message": "success"
}
```

### Response (ошибка валидации)
```json
{
  "errors": {
    "name": ["Поле name обязательно."],
    "email": ["Поле email должно быть валидным."]
  }
}
```

### Как я использую AI в работе (описано в портфолио)
Простой код пишу сама — это быстрее, чем объяснять задание. AI включаю там, где он реально экономит время:

- **Сложная логика и архитектура** — обсуждаю подходы, оцениваю варианты
- **Незнакомая технология** — изучаю документацию вместе с AI
- **Рутина** — генерирую однотипный код
- **Дебаг** — AI помогает посмотреть на проблему иначе
- **Рефакторинг** — проверяю код на чистоту
